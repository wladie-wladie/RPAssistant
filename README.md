# RPAssistant

Рабочее пространство для мастеров и игроков настольных ролевых игр.

**Открыть:** https://wladie-wladie.github.io/RPAssistant/

## Что уже есть
- Вход для мастеров и игроков (аккаунты хранятся в браузере)
- Проекты-игры с обязательным выбором игровой системы (правила подключим позже)
- Доска мастера в стиле Miro: стикеры, текст, 8 фигур, стрелки с привязкой к объектам
  (прямые / ломаные / кривые), карандаш и ластик, фреймы, изображения (drag&drop, Ctrl+V),
  выделение рамкой, ресайз, блокировка, слои, отмена/повтор, копирование, масштаб и панорама
- Код приглашения игроков, доступ игроков к доске (просмотр / скрыта), экспорт и импорт проекта
- Заготовки вкладок: Персонажи, Сессии, Заметки, Правила

## Установка как программы
Откройте ссылку в Chrome/Edge → значок «Установить» в адресной строке.
Обновления подтягиваются автоматически при следующем запуске.

## Горячие клавиши доски
V выбор · H рука · N стикер · T текст · R фигура · O эллипс · L стрелка · P карандаш · E ластик ·
F фрейм · I картинка · Del удалить · Ctrl+Z/Y · Ctrl+D дублировать · Ctrl+A · [ ] слои ·
колесо — масштаб · пробел/ПКМ + тянуть — панорама · Shift+1 показать всё
